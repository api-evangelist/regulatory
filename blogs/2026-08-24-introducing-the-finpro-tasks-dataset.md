Introducing the FINPRO Tasks Dataset K29547 Mon, 08/24/2026 - 18:47 We're excited to announce the FINPRO Tasks dataset, which enables firm users to automatically retrieve all FINPRO tasks and alerts for their registered representatives. The dataset supports only synchronous GET calls and returns all active tasks for a given individual. Tasks related to the following categories for an individual are included: Disclosure Letter Task Exam Schedule Task U4 Filing Task E-Signature Task Attestation Task Annual Regulatory Element CE (BDCE) Firm Assigned CE Task IAR CE Task Qualification Exam Waiver C
