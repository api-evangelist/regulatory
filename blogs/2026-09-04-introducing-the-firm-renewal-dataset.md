Introducing the Firm Renewal Dataset K29547 Fri, 09/04/2026 - 10:28 We're excited to announce the Firm Renewal dataset, which serves as a reference for firms to determine the annual renewal fees charged per registered individual.The dataset supports asynchronous GET calls and provides a JSON file output. Note: The dataset reflects the prior year's renewal data until current-year renewal statements become available in CRD.
