API Platform September 28, 2026 Release Notes K29547 Sun, 09/27/2026 - 13:45 API Console Fixed an issue with the state dropdown when creating an API Credential. Report Cards via API Added the ability to filter by "reportView" for all TRACE Report Card datasets. This filter is optional; by default, the view is set to "All." Introduced two new datasets: TRACE Foreign Sovereign Debt Summary : The TRACE Quality of Markets Report Card for Foreign Sovereign Debt dataset is a monthly status report for trades that a member firm reported to TRACE.
